# Vydria Hra (Godot MVP+) 

## Stav po 6 sprintoch (stabilita/test readiness)
- modular spawn director + balance constants
- difficulty phases: Early / Mid / Late
- seed mode pre reprodukovatelne spawny
- pause flow cez ESC + výsledková obrazovka
- expanded game-over results (čas, max hĺbka, zásahy)
- debug overlay (phase/spawn interval/active entities)
- QA checklist pripraveny v `QA_CHECKLIST.md`

## Ovládanie
- Pohyb: `WASD` alebo šípky
- Hod kamienka: `Space`
- Pauza: `ESC`
- Reštart po prehre: `Enter`
